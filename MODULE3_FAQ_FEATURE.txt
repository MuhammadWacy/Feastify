MODULE 3 - MEMBER 1 - FEATURE 2
Interactive Caterer FAQ

Customer flow:
Customer feed -> click caterer name -> customer-facing caterer profile -> Questions & Answers -> post question -> question saved in MongoDB -> all customers visiting that caterer profile can see it.

Seller flow:
Seller navbar -> FAQs -> see questions for own catering listing -> post/update answer -> answer saved in MongoDB -> all customers see the answer on the public profile.
